# EMAR Boutique - Catálogo Web & Panel de Control

Este proyecto está construido con **React**, **Vite** y **Tailwind CSS**, diseñado como una solución de e-commerce minimalista y elegante para moda femenina.

## 🚀 Cómo ejecutar localmente:

1. Extrae este archivo ZIP en tu computadora.
2. Abre la terminal en la carpeta extraída `emar-boutique`.
3. Instala las dependencias ejecutando:
   ```bash
   npm install
   ```
4. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
5. Abre el enlace indicado (usualmente `http://localhost:5173`) en tu navegador.

## 🌐 Cómo desplegar en Vercel o Netlify:

- **Netlify:** Ejecuta `npm run build` y arrastra la carpeta `dist` generada a Netlify Drop.
- **Vercel:** Sube el proyecto a GitHub y conéctalo directamente a Vercel.
